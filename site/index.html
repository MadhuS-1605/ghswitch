an identity document for your terminal

One passport.
Every account you run.

ghswitch is the single document git checks before every commit — author, SSH key, GPG signature, and gh auth, all issued together, all scoped to the shell you're standing in. Carry work in one terminal and personal in another; neither one stamps over the other.

Declaration

“Every tool that just flips gh auth switch is checking one document instead of the whole file — an API token is not your identity. Author, key, and signature have to travel together, or the wrong name ends up on the wrong repo.”
gh·switch Issued per terminal, via session env vars — never a shared global file. Open two shells, hold two identities, at the same time.
